1. ONLINE ZETTEN MET GITHUB
=====================================================
1. Maak op github.com een repository, bv. "paindumie". Zet ze op
   PUBLIC: GitHub Pages werkt niet bij een private repository op een
   gratis account.
2. Zet ALLE bestanden uit deze map in de repository (index.html moet
   bovenaan staan, niet in een submap). De map "_bronbestanden" mag
   mee, die doet online niets.
3. Repository > Settings > Pages:
      Source: Deploy from a branch
      Branch: main   /  (root)
   Na een minuut staat de site online.
4. Eigen domeinnaam: Settings > Pages > Custom domain > je domein
   invullen en opslaan. GitHub maakt zelf een CNAME-bestand aan.
   Zet daarna bij je domeinnaamprovider deze records:
      A     @    185.199.108.153
      A     @    185.199.109.153
      A     @    185.199.110.153
      A     @    185.199.111.153
      CNAME www  <jouw-github-gebruiker>.github.io
   Vink daarna "Enforce HTTPS" aan.
5. Het CNAME-bestand met je domein zit er al in, dus GitHub pikt
   paindumie.be vanzelf op. Vink 'Enforce HTTPS' aan zodra het kan.

De eerste keer vraagt het dashboard om een GitHub-sleutel (token).
Die maak je zo aan:
   github.com > je foto rechtsboven > Settings
   > Developer settings (helemaal onderaan links)
   > Personal access tokens > Fine-grained tokens > Generate new token
   > Repository access: enkel de repository van de website
   > Permissions > Repository permissions > Contents: Read and write
   > Generate token, en de sleutel plakken in het dashboard.
De sleutel wordt enkel op jouw eigen toestel bewaard.

WAT KAN JE AANPASSEN
 - Teksten: klik op een tekst in het voorbeeld en typ.
 - Prijzen: net zoals gewone tekst. Bij de reuzepannenkoeken opent er
   een venstertje voor de prijs van 1 stuk en van 2 stuks.
 - Foto's: klik op een foto en kies een nieuwe. Ze wordt automatisch
   verkleind. Foto's krijgen een nieuwe naam, zodat bezoekers meteen
   de nieuwe versie zien.
 - Instellingen (knop rechtsboven): openingsuren, verlofdagen,
   telefoon, e-mail, Facebook, Instagram, Google en alle regels van
   de reservatiemodule.
Druk daarna op PUBLICEREN. GitHub bouwt de site opnieuw op; na een
halve tot twee minuten staat alles online.

BELANGRIJK
 - De aanmelding op het dashboard is een slot op de deur, geen kluis.
   De echte beveiliging is de GitHub-sleutel: zonder sleutel kan
   niemand iets wijzigen. Deel die sleutel dus met niemand.
 - Werk niet met twee mensen tegelijk in het dashboard.
 - Alles wordt bewaard in GitHub, dus elke aanpassing is omkeerbaar.
   Verkeerd gepubliceerd? Marleo kan alles in één klik terugzetten.

5. RESERVATIES IN HET DASHBOARD (aanrader)
=====================================================
Standaard komen reservaties enkel per e-mail binnen. Wil je ze ook in
het dashboard zien, met een knop om te bevestigen of te annuleren,
dan zet je eenmalig een gratis Google-script op. Duurt vijf minuten.

 1. Ga naar https://sheets.new en noem het blad
    "Pain du Mie - reservaties".
 2. Menu Extensions (Extensies) > Apps Script.
 3. Wis alles in het venster en plak de volledige inhoud van
    _bronbestanden/google-apps-script.js.
 4. Bovenaan dat script staan twee regels. Controleer ze:
       var MAIL    = "paindumie.bazel@gmail.com";
       var SLEUTEL = "paindumie-2026";
    De sleutel mag je vrij kiezen, zolang ze straks overeenkomt.
 5. Klik op Deploy (Implementeren) > New deployment (Nieuwe
    implementatie) > kies bij type "Web app" en zet:
       Execute as      : Me (Ikzelf)
       Who has access  : Anyone (Iedereen)
    Klik Deploy en geef Google de gevraagde toestemming.
    (Google waarschuwt dat het script niet geverifieerd is. Klik op
     "Advanced" / "Geavanceerd" en dan op "Go to ... (unsafe)". Dat is
     je eigen script, dus dat mag.)
 6. Kopieer het adres dat eindigt op /exec.
 7. Open het dashboard > Instellingen > Reservaties bewaren.
    Plak het adres en dezelfde sleutel. Bewaren en Publiceren.
 8. Doe een testreservatie op de site en kijk of ze verschijnt onder
    de knop "Reservaties" in het dashboard.

Vanaf dan komt elke aanvraag op drie plaatsen toe: in de mailbox,
in het Google-blad en in het dashboard, en de klant krijgt meteen een
ontvangstmail. Klik je in het dashboard op Bevestigen of Annuleren,
dan krijgt de klant daar ook een mail van.

In het dashboard staat onder Reservaties een kalender: per dag zie je
hoeveel aanvragen er zijn (rood = nieuw, groen = bevestigd) en hoeveel
personen. Klik op een dag voor de namen en uren. Daar kan je ook
annuleren, of een geannuleerde reservatie terugzetten.

Met de knop "+ Reservatie ingeven" zet je een telefonische of mondelinge
reservatie in de kalender. Die staat meteen als bevestigd.

BESCHIKBAARHEID OP DE WEBSITE
Alles wat niet geannuleerd is, telt mee: de website weet per tijdslot
hoeveel plaatsen er nog vrij zijn in de tearoom. Een tafel blijft
90 minuten bezet (aanpasbaar: durationMinutes in config.js). Volle
uren kan een bezoeker niet meer kiezen, en het aantal personen wordt
beperkt tot wat er nog vrij is. Annuleer je iets, dan komt de plaats
meteen weer vrij.
