Eenmalig instellen

Het dashboard bewaart je aanpassingen rechtstreeks in GitHub. Daarvoor is één sleutel nodig.

Hoe maak ik zo'n sleutel?
  1. Meld je aan op github.com.
  2. Klik op je foto rechtsboven en ga naar Settings.
  3. Helemaal onderaan links: Developer settings.
  4. Personal access tokens → Fine-grained tokens → Generate new token.
  5. Geef als naam "Dashboard Pain du Mie", kies bij Repository access enkel de repository van de website.
  6. Bij Permissions → Repository permissions → zet Contents op Read and write.
  7. Klik Generate token en plak de sleutel hierboven. Bewaar ze ook ergens veilig.
